# truenas_snapshot_task (Resource)

Manages a periodic snapshot task, which takes ZFS snapshots of a dataset on a cron schedule and expires them once their lifetime elapses.

## Example Usage

### Nightly Recursive Snapshots

```terraform
# Snapshot a dataset and its children every night at 02:00, keeping two weeks
resource "truenas_dataset" "data" {
  pool = "tank"
  path = "data"
}

resource "truenas_snapshot_task" "nightly" {
  dataset   = truenas_dataset.data.id
  recursive = true

  naming_schema  = "nightly-%Y-%m-%d_%H-%M"
  lifetime_value = 2
  lifetime_unit  = "WEEK"

  schedule = {
    minute = "0"
    hour   = "2"
  }
}
```

### Hourly Snapshots Within a Maintenance Window

```terraform
resource "truenas_snapshot_task" "hourly" {
  dataset = "tank/vm"

  naming_schema  = "hourly-%Y-%m-%d_%H-%M"
  lifetime_value = 48
  lifetime_unit  = "HOUR"

  schedule = {
    minute = "0"
    hour   = "*"
    begin  = "18:00"
    end    = "06:00"
  }
}
```

### Recursive Snapshots Excluding a Child Dataset

```terraform
resource "truenas_snapshot_task" "weekly" {
  dataset   = "tank/data"
  recursive = true
  exclude   = ["tank/data/scratch"]

  naming_schema  = "weekly-%Y-%m-%d"
  lifetime_value = 3
  lifetime_unit  = "MONTH"

  schedule = {
    minute = "0"
    hour   = "1"
    dow    = "7"
  }
}
```

> **Note:** `dataset` is a ZFS dataset name such as `tank/data`, not a mount point. Use a dataset resource's `id` attribute rather than its `full_path`.

> **Note:** `naming_schema` must include enough strftime time fields to give every run a distinct snapshot name; TrueNAS rejects a schema that could collide.

> **Note:** `exclude` is only accepted when `recursive` is `true`. TrueNAS rejects the combination on apply.

> **Note:** Deleting a task leaves the snapshots it already took in place.

## Import

Periodic snapshot tasks can be imported using the numeric task ID:

```shell
terraform import truenas_snapshot_task.example 1
```

## Schema

### Required

- `dataset` (String) Dataset to snapshot, as a ZFS name such as "tank/data" (not a mount point).

### Optional

- `allow_empty` (Boolean) Take a snapshot even when nothing changed since the previous run.
- `enabled` (Boolean) Enable or disable the task.
- `exclude` (List of String) Child datasets to leave out of a recursive snapshot. Only valid when `recursive` is true.
- `lifetime_unit` (String) Unit `lifetime_value` is counted in. Valid values: HOUR, DAY, WEEK, MONTH, YEAR.
- `lifetime_value` (Number) Number of `lifetime_unit` periods to keep snapshots for before they are eligible for deletion.
- `naming_schema` (String) strftime pattern used to name the snapshots this task takes. It must produce a unique name for every run, so it has to include enough time fields to distinguish them.
- `recursive` (Boolean) Also snapshot the child datasets of `dataset`.
- `schedule` (Attributes) Cron schedule the task runs on. Omit it to snapshot hourly, on the hour, every day. (see [below for nested schema](#nestedatt--schedule))

### Read-Only

- `id` (String) Periodic snapshot task ID.
- `vmware_sync` (Boolean) Whether VMware virtual machines are synchronised before snapshots are taken. Derived from the VMware-snapshot configuration, not settable here.
