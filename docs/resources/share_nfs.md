# truenas_share_nfs (Resource)

Manages an NFS share (export). Creating a share does not start the NFS service; enable the service separately.

## Example Usage

### Basic NFS Share

```terraform
# Export a dataset over NFS to a single subnet
resource "truenas_dataset" "media" {
  pool = "tank"
  path = "media"
}

resource "truenas_share_nfs" "media" {
  path    = truenas_dataset.media.full_path
  comment = "Media library"

  networks = ["10.0.0.0/24"]
  security = ["SYS"]

  maproot_user  = "root"
  maproot_group = "root"
}
```

### Read-Only Share Restricted to Specific Hosts

```terraform
resource "truenas_share_nfs" "backups" {
  path    = "/mnt/tank/backups"
  comment = "Offsite backup target"

  hosts = ["backup01.example.com", "10.0.0.50"]
  ro    = true

  mapall_user  = "nobody"
  mapall_group = "nogroup"
}
```

> **Note:** `maproot_*` and `mapall_*` are mutually exclusive, and each `_group` attribute requires its matching `_user` attribute. Both rules are enforced during `terraform plan`.

> **Note:** Creating a share does not start the NFS service. Enable the NFS service separately before clients can mount the export.

> **Note:** `aliases` is read-only. TrueNAS accepts the field but discards any value, so it always reads back empty.

## Import

NFS shares can be imported using the numeric share ID:

```shell
terraform import truenas_share_nfs.example 1
```

## Schema

### Required

- `path` (String) Local path to be exported.

### Optional

- `comment` (String) User comment associated with the share.
- `enabled` (Boolean) Enable or disable the share.
- `expose_snapshots` (Boolean) Expose the ZFS snapshot directory over NFS. TrueNAS Enterprise only; the export path must be the root of a ZFS dataset.
- `hosts` (List of String) IP addresses or hostnames allowed to access the share. If empty, all hosts are allowed.
- `mapall_group` (String) Map all client groups to this group. Requires `mapall_user`.
- `mapall_user` (String) Map all client users to this user. Conflicts with the maproot attributes.
- `maproot_group` (String) Map the root group of clients to this group. Requires `maproot_user`.
- `maproot_user` (String) Map the root user of clients to this user. Conflicts with the mapall attributes.
- `networks` (List of String) Authorized networks allowed to access the share, in "network/mask" CIDR notation. If empty, all networks are allowed.
- `ro` (Boolean) Export the share as read only.
- `security` (List of String) Security schemes offered by the export, in order of preference. Valid values: SYS, KRB5, KRB5I, KRB5P.

### Read-Only

- `aliases` (List of String) Share aliases. Read-only: TrueNAS accepts this field but discards any value, so it is always empty.
- `id` (String) NFS share ID.
- `locked` (Boolean) Whether the share is located on a locked dataset.
